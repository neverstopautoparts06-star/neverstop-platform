# NEVERSTOP Platform

NEVERSTOP 汽车零部件数字化平台。

当前第一阶段主要面向越南汽车零部件市场，主营汽车减震器（Shock Absorber / Giảm xóc ô tô）。

## V1 核心目标

建立一个：

车型查询 + 产品数据库 + 产品展示 + 询价 + 订单 + BIDV VietQR 支付 + 后台管理

的一体化独立站。

## 核心业务流程

客户进入网站
→ 按车型 / OE号 / 产品编号查询
→ 找到适配产品
→ 查看产品信息
→ Zalo咨询或提交询价
→ 销售确认车型和价格
→ 生成订单
→ BIDV VietQR付款
→ 人工确认到账
→ 备货
→ 发货
→ 完成订单
